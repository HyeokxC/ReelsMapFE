# 디자인 구현 기록

2026-11-11. 앱 모드. 기존 iOS Liquid Glass 시스템을 유지하는 구현입니다.

## 근거

`../mockups/osm/ios-glass.html`, `ios.css`, `iosgl.css`, `lens.js`, `iosgl.js`, `icons.js`, `data.js`를 읽고 지도, 패널, 탭, 아이콘과 굴절을 이식했습니다. 화면 내용은 `.omo/claude-design/merged/`의 지정된 네 문서를 사용했습니다. 사용자 지시대로 새 디자인 방향을 선택하거나 외부 이미지로 대체하지 않았습니다.

색상과 글자 크기, 간격과 모서리는 CSS 토큰을 공유합니다. 패널, 섹션, 토글, 경고창, 아이콘은 공용 React 컴포넌트입니다. 어두운 보조 글자와 별도 경고창 표면을 사용해 지도 위 글자의 대비를 유지했습니다.

## 검증

디자인 린터: 0 FAIL, 16 WARN. `shadow`, `glass` 경고는 사용자가 지정한 지도 위 글래스 패널과 원형 컨트롤에 해당하므로 유지합니다. `eyebrow` 경고의 `.section-label`은 실제 그룹 제목입니다. 마케팅용 장식 라벨이 아닙니다.

Playwright: 1440x900 DPR 2 및 390x844 DPR 3에서 10개 경로와 삭제 경고창을 캡처했습니다. 모든 화면에서 WebGL 렌즈 활성화와 가로 넘침 없음을 확인했습니다. 투명도 줄이기에서도 별도로 캡처하고 렌즈 해제 및 불투명 CSS 대체를 검증했습니다.

직접 스크린샷을 보고 전체 화면을 잘못 렌즈 대상으로 잡던 문제, 모바일 알림의 버튼 가림, 지도 핀의 시트 가림, 시작 화면의 지도 컨트롤 겹침, 경고창 뒤 텍스트 비침을 수정했습니다. 사용자 지시가 재위임을 금지하므로 별도 리뷰 에이전트는 사용하지 않았습니다.
